# TecnoFit - Módulo de Registro e Inicio de Sesión

Este proyecto corresponde a la **Evaluación Parcial 1** del curso de Desarrollo Web (DSY1104).

## Descripción del Proyecto
Plataforma web front-end desarrollada para la tienda **TecnoFit**, orientada a la venta de dispositivos de monitoreo deportivo. Incluye un módulo de registro dinámico de dispositivos vinculados y un inicio de sesión con validación de datos en tiempo real.

## Tecnologías Utilizadas
* HTML5
* CSS3
* JavaScript Vanilla (ES6)

## Características e Indicadores
* **Registro de Usuario:** Validación estricta de correo institucional (`@duoc.cl` o `@profesor.duoc.cl`) y contraseñas seguras.
* **Componentes Dinámicos:** Generación y eliminación en tiempo real de campos para añadir múltiples dispositivos con validación de número de serie (12 caracteres).
* **Diseño Responsivo:** Adaptado a pantallas móviles y de escritorio.
